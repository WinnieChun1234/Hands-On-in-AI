# AI Hands-On Notebooks

## Overview
This repository contains a collection of Jupyter notebooks that provide hands-on experience with different artificial intelligence techniques and frameworks. Each notebook focuses on a specific concept or algorithm, allowing me to learn and experiment with AI technologies incrementally.

## Notebooks in this Repository

### 1. Checkpoint1b_TensorFlow2
**Introduction to TensorFlow 2**
- Learn the basics of TensorFlow 2, Google's machine learning framework
- Build and train basic neural network models
- Understand TensorFlow's eager execution mode
- Implement data pipelines using tf.data
- Visualize training process and model performance
- Suitable for beginners who want to get started with deep learning using TensorFlow

### 2. Checkpoint1c_PyTorch
**Introduction to PyTorch**
- Explore PyTorch, a popular deep learning framework 
- Understand PyTorch's dynamic computation graph
- Build and train neural network models using PyTorch
- Learn about PyTorch tensors, autograd functionality, and optimization
- Implement data loading and transformation with PyTorch's utilities
- Great for beginners wanting to understand an alternative approach to TensorFlow

### 3. Checkpoint2_Clustering
**Unsupervised Learning with Clustering Algorithms**
- Explore unsupervised learning techniques for pattern discovery
- Implement and compare different clustering algorithms:
  - K-means clustering
  - Hierarchical clustering
  - DBSCAN (Density-Based Spatial Clustering)
- Visualize cluster results using dimensionality reduction
- Apply preprocessing techniques and evaluate cluster quality
- Learn how to determine the optimal number of clusters
- Practical examples of clustering in real-world datasets

### 4. Checkpoint3_ObjectDetection
**Computer Vision: Object Detection**
- Implement object detection algorithms on images and video
- Explore modern deep learning approaches for object detection
- Learn about region proposal networks, anchor boxes, and IoU
- Use pre-trained models for transfer learning
- Visualize detection results with bounding boxes
- Evaluate model performance using precision, recall, and mAP
- Practical applications in real-world computer vision tasks

### 5. Checkpoint4_ExplainableAI
**Explainable AI Techniques**
- Understand the importance of model interpretability
- Implement various techniques to explain AI model decisions:
  - Feature importance
  - LIME (Local Interpretable Model-agnostic Explanations)
  - SHAP (SHapley Additive exPlanations) values
  - Grad-CAM for visualizing CNN decisions
- Compare black-box vs. interpretable models
- Learn how to balance performance with explainability
- Practical guidelines for implementing responsible AI

### 6. Checkpoint5_DeepQLearning
**Reinforcement Learning with Deep Q-Learning**
- Introduction to reinforcement learning concepts
- Implement Deep Q-Networks (DQN) for sequential decision-making
- Understand Q-learning, experience replay, and the target network
- Build agents that learn to play games or solve environments
- Explore techniques for stable training of deep RL agents
- Visualize agent learning progress and performance
- Applications in gaming, robotics, and resource optimization
